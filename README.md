# BuffAnnounce Duo

Два полноценных экземпляра BuffAnnounce с отдельными настройками и независимым размещением окон.

## Установка
1. Распакуйте архив ветки.
2. Скопируйте обе папки `BuffAnnounceDuo` и `BuffAnnounceDuo2` в каталог игры `data/Mods/Addons/`.
3. Перезапустите игру или обновите список аддонов.

## Управление
- Единственная кнопка **BuffAnnounce Duo** управляет видимостью обеих панелей.
- Второй экземпляр не создаёт вторую кнопку в AO Panel.
- У каждого экземпляра свой конфиг и свой список отслеживаемых бафов.
- Начальные позиции разнесены по горизонтали; каждое окно можно перетаскивать отдельно.

Обе папки содержат собственный MainForm, Lua-скрипты, виджеты и файлы ресурсов. Это два отдельных аддона, а не две ссылки на одну и ту же панель.
