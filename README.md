# BuffAnnounce Duo

**Один аддон — два независимых окна.**

В аддон объединены два экземпляра интерфейса BuffAnnounce. У обоих окон свой набор виджетов, собственное состояние Lua, отдельные настройки и отдельное положение.

## Установка
1. Скачайте ZIP этой ветки и распакуйте архив.
2. Переименуйте распакованную папку в `BuffAnnounceDuo`.
3. Поместите её целиком в `data/Mods/Addons/`.
4. Убедитесь, что в каталоге аддона находится один файл `AddonDesc.(UIAddon).xdb`, затем перезапустите игру.

## Управление
- Единственная кнопка BuffAnnounce Duo открывает и скрывает оба окна одновременно.
- У каждого окна собственные вкладки, фильтры бафов и параметры отображения.
- Второе окно начинается правее первого; оба окна можно перетаскивать независимо.
- Настройки первого и второго окон сохраняются отдельно.

Вторая панель встроена как дочерняя ветка единственной формы аддона. Второй UIAddon и отдельная кнопка для него не требуются.
